PRIVACY POLICY

Your conversations stay yours.

Conversation Manager does not operate a developer-controlled server, sell user data, or use analytics or advertising trackers.

Effective August 26, 2026 · English followed by 简体中文

English

Conversation Manager for ChatGPT is an independent browser extension that helps users organize and manage conversations in their own ChatGPT account. The current version lets users select and delete conversations through a paced, resumable queue. It is not affiliated with or endorsed by OpenAI.

Data the extension handles

To provide its user-facing functionality, the extension reads conversation metadata from the user's signed-in ChatGPT tab, including conversation identifiers, titles, and available timestamps. It stores the selected deletion queue, task status, retry information, and limited diagnostic logs in chrome.storage.local on the user's device.

The extension temporarily obtains the current ChatGPT session access token inside the ChatGPT page solely to make same-origin requests requested by the user. The token is not returned to the extension service worker, written to extension storage, included in logs, or sent to the developer.

How data is used

Conversation metadata is used only to display the user's conversation list and carry out deletion tasks selected by the user. Queue data is used only to show progress, resume interrupted work, apply rate-limit backoff, and report failures.

Data sharing and remote collection

The extension does not operate a developer-controlled server. It does not sell user data, use analytics, create advertising profiles, or transmit conversation titles, identifiers, ChatGPT credentials, queue contents, or browsing activity to the developer or advertising companies.

List and deletion requests are sent only to https://chatgpt.com as necessary to provide the extension's stated function. The optional Buy Me a Coffee button opens https://buymeacoffee.com/ktventures without adding conversation data or extension telemetry to the link.

Retention and deletion

Queue state and limited logs remain in local extension storage so interrupted tasks can recover. Starting a new task replaces the active queue state, and diagnostic list logs are replaced when a new list load begins. Users can delete all locally stored extension data by uninstalling the extension or clearing its extension data in Chrome.

Security and Limited Use

All network requests use HTTPS. Conversation Manager's use of information obtained through Chrome permissions complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. User data is used only to provide the extension's user-facing conversation management features.

Third-party services

ChatGPT and Buy Me a Coffee are third-party services governed by their own privacy policies. Conversation Manager relies on ChatGPT website interfaces that may change over time.

Changes and contact

This policy may be updated if the extension's data practices change. Material changes will be reflected in the extension listing or interface as required. Questions can be submitted through the support page.

简体中文

Conversation Manager for ChatGPT 是一个独立浏览器扩展，帮助用户整理和管理自己 ChatGPT 账户中的对话。当前版本支持通过控制节奏的可恢复队列选择并删除对话。本扩展与 OpenAI 无隶属或官方认可关系。

扩展处理的数据

为了提供面向用户的功能，扩展会从用户已登录的 ChatGPT 标签页读取对话元数据，包括对话 ID、标题和可用时间。扩展还会将用户选择的删除队列、任务状态、重试信息和有限的诊断日志保存在用户设备上的 chrome.storage.local 中。

扩展会在 ChatGPT 页面内部临时取得当前会话 access token，仅用于执行用户要求的同源请求。Token 不会返回扩展 Service Worker、写入扩展存储、出现在日志中或发送给开发者。

数据用途

对话元数据仅用于显示用户的对话列表并执行用户选择的删除任务。队列数据仅用于显示进度、恢复中断任务、执行限流退避和报告失败原因。

数据共享和远程收集

本扩展没有开发者控制的服务器，不出售用户数据，不使用分析服务，不建立广告画像，也不会向开发者或广告公司传输对话标题、ID、ChatGPT 凭据、队列内容或浏览活动。

列表和删除请求仅在实现扩展功能所必需时发送到 https://chatgpt.com。可选的“请我喝杯咖啡”按钮会打开 https://buymeacoffee.com/ktventures，链接中不会附带对话数据或扩展遥测信息。

数据保留和删除

队列状态和有限日志会保存在本地扩展存储中，以便恢复中断任务。创建新任务时会替换当前队列；重新读取列表时会替换列表诊断日志。用户可以通过卸载扩展或在 Chrome 中清除扩展数据来删除所有本地保存的数据。

安全与 Limited Use

所有网络请求均使用 HTTPS。Conversation Manager 对通过 Chrome 权限获得的信息的使用遵守 Chrome Web Store User Data Policy，包括 Limited Use 要求。用户数据仅用于提供扩展面向用户的对话管理功能。

第三方服务

ChatGPT 和 Buy Me a Coffee 是第三方服务，适用其各自的隐私政策。本扩展依赖可能随时间变化的 ChatGPT 网页接口。

更新与联系

如果扩展的数据处理方式发生变化，本政策可能更新；重大变化将按要求在扩展商店页面或用户界面中披露。如有问题，请通过支持页面联系我们。
